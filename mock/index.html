18 minutes

Round 2 — short answers

Two or three sentences each. Push for the why, not the definition. If they give you a textbook line, ask “give me an example” and wait.

What is the difference between a list and a tuple?
A list can be changed after you make it — you can add, remove and replace. A tuple cannot. Use a tuple when the values must not change, like a date of birth or a pair of coordinates.
What is the difference between a list and a set?
A list keeps duplicates and keeps the order. A set throws duplicates away and does not promise any order. If you want the unique values out of a column, put it in a set.
Why would you use a dictionary instead of two lists?
Because the key and the value are tied together in one place. With two lists you have to keep them in the same order yourself, and the day one list gets sorted and the other does not, every answer is wrong and nothing warns you.
What is the difference between == and =?
= puts a value into a variable. == asks a question — are these two the same? One stores, one compares.
What is the difference between / and //?
/ gives the full answer with the decimal — 7 / 2 is 3.5. // drops the decimal — 7 // 2 is 3.
Why does "5" + "5" give 55 and not 10?
Because those are not numbers, they are text. For text the plus sign means join, not add. This is why input() catches people — it always gives you text.
What does strip() do, and when does it actually matter?
It removes spaces from the front and the back of text. It matters when you are comparing — "Asha " and "Asha" are not equal, and you cannot see the difference on screen.
What is slicing? Give an example.
Taking a piece out of a string or a list by position. "analytics"[2:5] gives aly — it starts at position 2 and stops before position 5.
What is a list comprehension and why use one?
A way to build a new list in one line instead of writing a loop with append. [x*x for x in range(4)] gives [0, 1, 4, 9]. Shorter to read, and you can put a condition on the end.
What are the three file modes and what does each one do?
r read, and the file must already exist. w write, and it empties the file the moment it opens. a append, adds to the end and keeps what was already there.
Why is with open(...) better than open() and close()?
Because it closes the file for you, even if the program crashes in the middle. With close() you have to remember, and forgetting usually looks like it worked.
Why handle an error instead of letting the program crash?
Because a crash stops everything. If you are processing two hundred rows and row five is broken, a crash loses the other one hundred and ninety-five. Handling it lets you skip that row and carry on.
What is the difference between a class and an object?
The class is the plan. The object is a thing built from that plan. One Student class, and then fifty student objects each holding different marks.
What is self?
The particular object we are talking about. When you write s.passed(), Python quietly passes s in as self. That is why you never type it yourself when you call the method.
What does __init__ do?
It runs automatically the moment you create an object, and its job is to put the starting values inside it. You never call it by name yourself.
Explain encapsulation in your own words.
Keeping the data and the things that work on that data in one box. The object carries its own values, so you do not have to hand them over every time.
Explain abstraction, and how it is different from encapsulation.
Abstraction is giving somebody a simple button and hiding the complicated part behind it. The difference: encapsulation is packing the box, abstraction is not having to look inside it.
Explain inheritance with an example.
A new class starts with everything an existing class had. class SalaryColumn(Column) gets __init__ and every method of Column for free, and can then add its own.
Explain polymorphism with an example you have actually used.
The same word doing the right thing for different types. len("hello") is 5 and len([1,2,3]) is 3, and you never had to say which. The plus sign adds numbers and joins text.
What is the difference between append() and extend()?
append adds one thing — give it a list and you get a list inside your list. extend adds each item of what you give it, one by one.
What is the difference between remove() and pop()?
remove takes the value and deletes the first match. pop takes the position, deletes it, and hands the item back to you.
What is the difference between get() and square brackets on a dictionary?
Square brackets crash with a KeyError if the key is not there. get() returns None instead, so your program keeps running.
Why does a set not allow duplicates, and where is that useful?
Because it is built to hold each value once. It is the fastest way to answer “how many different values are in this column?” — put the column in a set and take its length.
What is an index, and why does it start at zero?
The position of an item. It starts at zero because the index is really a distance from the start — the first item is zero steps in.
What is the difference between is and ==?
== asks do these hold the same value. is asks are these the exact same object in memory. For your work you almost always want ==.
What does it mean that a list is mutable?
It can be changed in place, without making a new one. Which also means if two names point at the same list, changing it through one name changes what the other one sees.
What is the difference between a parameter and an argument? August only
The parameter is the name in the def line. The argument is the actual value you hand over when you call it. Parameter is the slot, argument is what goes in it.
What is a default argument? August only
A value the parameter falls back on when the caller does not give one. def greet(name, greeting="Hello") — you can call it with one argument or two.
What is the difference between break and continue? August only
break leaves the loop completely. continue skips the rest of this round and goes to the next one. The loop is still running.
When would you use a while loop instead of a for loop? August only
When you do not know how many rounds you need. A for loop runs over a list you already have. A while loop keeps going until a condition stops being true.
What is recursion? August only
A function that calls itself on a smaller version of the problem, until it hits a case small enough to answer directly. That stopping case is the base case, and without it the function never ends.
What do map() and filter() do? August only
map runs a function on every item and gives back the results. filter runs a test on every item and gives back only the ones that pass.

20 minutes

Round 4 — explain it properly

Long answers. Give them time and do not fill the silence. These are the ones that separate somebody who learned it from somebody who copied it. Ask for an example every single time.

Walk me through what happens, step by step, when Python runs a for loop over a list.
Python takes the first item out of the list and puts it into the loop variable. It runs everything indented under the for line using that value. Then it comes back, takes the next item, and does it again. When there are no items left it stops and carries on with the first line that is not indented.

What to listen for: that the indented block runs once per item, and that the loop variable is a fresh value each round, not the list itself.
You have a list of two hundred salaries and some of them are missing. Describe how you would find how many are missing.
Count the whole list with len(). Then go through it with a loop and count the ones that are actually a number, or build a new list of just those. The difference between the two counts is how many are missing.

What to listen for: the idea of counting two things and comparing, rather than trying to spot the gaps by eye. If they reach for a list comprehension with a condition, that is a strong answer.
What is the difference between a syntax error and an error that happens while the program is running?
A syntax error means Python could not even read your code — a missing bracket, a missing colon, wrong indentation. Nothing runs at all. An error while running means the code was readable and something went wrong part way through — dividing by zero, a missing file, converting "abc" to a number.

Why it matters: you can only catch the second kind with try and except. try will not save you from a missing bracket.
Why do we use try and except around file reading in particular?
Because the file is outside your program and you do not control it. It might have been moved, renamed, deleted, or still be downloading. Everything inside your program you can check; the file you cannot.

A good answer names the error — FileNotFoundError — and says what you would do instead of crashing: print a clear message, or carry on with the rows you did get.
Take a dictionary of names and marks. Explain how you would find the highest mark, out loud, without writing code.
Keep a variable for the best mark so far, starting at the first one. Go through the dictionary one key at a time. Each time, compare that person's mark with the best so far, and if it is bigger, replace it. At the end the variable holds the highest.

What to listen for: that they hold a running answer and update it. If they say max(), accept it and then ask them to describe how max must be doing it internally.
You wrote a class. Explain what actually happens, in order, when somebody writes s = Student("Asha", 72).
Python makes a new empty object from the Student plan. Then it automatically calls __init__, passing the new object in as self, and "Asha" and 72 as the other two parameters. Inside __init__, self.name = name stores the name onto that object. When __init__ finishes, the finished object is handed back and put into s.

What to listen for: that __init__ is called for them, and that self is the object being built.
Why does a data analyst need to understand classes at all, if they will never write one?
Because everything they use is an object. type(5) says class. A string is a class. Next module, a whole table will be a class and a single column will be another one. Every .something() they type is a method on an object.

The honest answer is: not so they can design classes, but so that when they pick up a library, they already understand the shape of what they are holding.
Give me a real situation where you would choose a tuple over a list, and defend it.
Anything that must not change: a date of birth, a pair of latitude and longitude, the fixed column headings of a file. The point is not speed — it is that the code cannot accidentally change it, and anybody reading the code can see that it was never meant to change.

Push back once: “but a list would also work”. A good candidate says yes, it would run, but the tuple says something to the next person who reads it.
What is the difference between printing something and returning it?
print puts it on the screen for a human to read, and then it is gone. The program cannot use it again. Returning hands the value back to the code, so you can store it in a variable and keep working with it.

The test: if a method prints, you cannot add its answer to anything. If it returns, you can.
You open a file with mode "w", and then close it without writing anything. What is in the file, and why does it matter?
It is empty. Mode w clears the file the moment it opens — it does not wait to see whether you write anything.

It matters because this is how people destroy a file they meant to read. They reach for w out of habit, nothing crashes, nothing warns them, and the data is gone.
Explain, step by step, what happens when a recursive function runs. Use a small example. August only
Take a function that adds up a list. It looks at the first number, then asks itself to add up the rest of the list, and adds the two together. That inner call does the same thing on a shorter list, and so on. Eventually the list is empty — that is the base case — and it returns zero without calling itself again. Then all the waiting calls finish, in reverse order.

What to listen for: the base case. Without it the function never stops. If they do not mention it, ask what happens when the list runs out.
What is a lambda, when would you use one, and when would you not? August only
A function written on one line with no name, usually handed straight to something else. map(lambda x: x * x, nums).

Use one when the job is tiny and you only need it in that one place. Do not use one when it needs more than one line, or when a name would explain what it does. A lambda you have to stop and decode is worse than a def.
When would a regular expression be the right tool, and when would you just use string methods? August only
Use string methods when you know exactly what you are looking for — a fixed word, a fixed separator. split, replace and strip are clearer and faster to read.

Use a regular expression when you are describing a shape rather than a value: any ten-digit number, anything that looks like an email, a date in any of three formats. The moment you find yourself writing five if statements to describe a pattern, that is the signal.

Round 5 — the trap questions

Short, and designed to be got wrong. Use these to find out who is reciting and who is thinking. If the room gets one wrong, that is the most useful thing that happens all session — teach it on the spot.

I did y = x with two lists, changed y, and x changed too. Is that a bug?
No. y = x did not copy anything — it gave the same list a second name. Both names point at one list. To get a real copy you need x.copy() or list(x).
Why is bool("False") True?
Because it is a string with five characters in it, not the word False. Any string that is not empty is True. Only "" is False.
"10" == 10 is False. Explain.
One is text and one is a number. They look the same on screen and they are different types, so they are not equal. This is exactly what bites people after input().
I wrote a method but when I call it nothing happens. What are the two most likely reasons?
Either it prints nothing and returns something, and you did not print the result. Or you referred to it without the brackets — s.passed instead of s.passed() — which hands you the method itself rather than running it.
I used pop() on an empty list. What happens?
It raises an IndexError. There is nothing at that position to remove. The same thing happens with [1,2,3][5].
Is a set ordered?
No. You cannot rely on the order and you cannot ask for s[0]. If you need order, convert it to a list and sort it.
Two objects of the same class — do they share their values?
No. Each object holds its own. The class is the plan; every object made from it has its own copy of the values that __init__ put there.
Does except catch a missing colon at the end of an if line?
No. That is a syntax error — Python cannot read the file at all, so nothing runs, including your try. except only catches things that go wrong while the program is running.
I wrote a function and nothing happened. Why? August only
Writing a function does nothing. It is a recipe on a shelf. It only runs when you call it by name with brackets.
My while loop never stops. What did I forget? August only
To change the thing the condition is testing. If i never increases, while i < 5 is true forever. Ctrl+C stops it.

How to run it

  1. Leave the switch on September B2 unless you are certain. The class merged five weeks ago and they sit in one room. Anything hidden in that view will make a September student look like they forgot something they were never shown.
  2. Say at the start that this is Python only. No NumPy, no Pandas, no statistics. The room relaxes and you get better answers.
  3. Do not go round the class in order. Jump. The moment it becomes predictable, everybody switches off until their turn is close.
  4. Take the answer from one person and the reason from another. It doubles the number of people thinking and it catches the ones who memorised the line without the idea.
  5. When the room gets one wrong, stop and teach it. That is worth more than the next three questions. Round 5 exists for exactly this.
  6. Write down what they miss. Whatever falls over today is what next week's NumPy sessions should open by repairing.
